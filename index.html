API Nima va U Qanday Ishlaydi?

API (Application Programming Interface, “dasturlash interfeysi”) dasturlar o’zaro gaplashishi uchun qoidalar to’plami. Bir dastur ikkinchisidan ma’lumot so’raydi yoki biror amalni bajarishni buyuradi, API esa buning yo’lini belgilaydi.

Hayotiy Misol (Ofitsiant Analogiyasi):

Restoranda mijoz oshxonaga o'tib ovqat pishirmaydi. Mijoz buyurtmani **ofitsiantga (API)** beradi. Ofitsiant so'rovni **oshxonaga (Server)** olib boradi va tayyor natijani mijozga olib keladi.

Mijoz (Client) va Server o'rtasidagi so'rov-javob zanjiri

1. REST API Arxitekturasi Asoslari

**REST** (Representational State Transfer) — veb-xizmatlar o’zaro HTTP orqali ma’lumot almashishining eng keng tarqalgan uslubi. Bu qat’iy standart emas, balki ma’lum tamoyillarga amal qiladigan API yaratish yondashuvi.

Resursga Yo'naltirilgan

Har bir obyekt o'zining aniq URL manziliga ega bo'ladi (`/api/products`).

Stateless (Holatsiz)

Har bir so'rov o'zida barcha kerakli ma'lumotlarni saqlaydi.

JSON Format

Ma'lumotlar universal JSON formatida uzatiladi.

2. CRUD Operatsiyalari va HTTP Metodlari

Ma'lumotlar bazasi bilan ishlashning to'rt asosiy ustuni:

GET

Olish (Read)

Serverdan ma'lumotlarni o'qish uchun. Status: 200 OK

POST

Yaratish (Create)

Serverga yangi ma'lumot qo'shish. Status: 201 Created

PUT

Yangilash (Update)

Mavjud ma'lumotlarni to'liq tahrirlash. Status: 200 OK

DELETE

O'chirish (Delete)

Ma'lumotni bazadan o'chirish. Status: 200 OK

Ma'lumotlar bazasi bo'ylab CRUD oqimi

3. Postman — API Tester Tool

**Postman** — bu dasturchilar va testerlarga API so'rovlarini yuborish, javoblarini tahlil qilish imkonini beruvchi vosita.

Asosiy Imkoniyatlari:

  • HTTP so'rovlarini (GET, POST, PUT, DELETE) vizual tarzda yuborish.
  • Headers (Sarlavhalar) va Authorization (Tokenlar) bilan ishlash.
  • Collections (To'plamlar) yaratib, loyiha API'larini guruhlash.
Postmanda so'rov yuborish va status kodni test qilish

4. Postmanda CRUD Test qilish Amaliyoti

1. GET: GET https://fake.jsonmockapi.com/products — Ro'yxatni olish.
2. POST: `POST` orqali Body qismida JSON ma'lumot yuborish (201 Created).
3. PUT: `PUT /products/{id}` orqali ma'lumotlarni o'zgartirish.
4. DELETE: `DELETE /products/{id}` orqali o'chirish.
Postmanda so'rov yuborish va status kodni test qilish interfeysi
